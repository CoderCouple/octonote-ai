## The four things you make

| | What it is |
| --- | --- |
| [Note](/guides/notes) | A document with headings, lists, code, math, mermaid diagrams and figures from your canvases. |
| [Canvas](/guides/canvases) | An infinite whiteboard for flows, maps and architecture diagrams. |
| [Project](/guides/projects) | One note and one canvas, side by side. |
| [Notebook](/guides/notebooks) | A folder that holds notes, canvases and projects. Publish one and it becomes a small website. |
