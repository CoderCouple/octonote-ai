A project pairs one note with one canvas: the writing and the drawing that explains it. Renaming the project renames both.

## Views

Switch with the three buttons in the project header:

- **Note only**
- **Note and canvas together** (Split, the default)
- **Canvas only**

The view you choose becomes the project's default, so readers of a published project see it the way you set it. On a phone held upright, Split stacks the note above the canvas.

## Figures in the note

Group shapes into a figure on the canvas ([how](/guides/canvases#figures)), then drag its handle into the note. It lands where you drop it and stays in sync with the drawing.

## Sharing

Share or publish the project from its header. The note and canvas inside go with it. A project's note or canvas can't be deleted on its own; delete the project instead.
