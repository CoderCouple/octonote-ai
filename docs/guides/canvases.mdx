A canvas is an infinite whiteboard with shapes, arrows, text, sticky notes, pencil and more. The tools in the canvas header:

| Tool | What it does |
| --- | --- |
| **Auto-shape** | Rough pencil strokes snap into a clean circle, ellipse, rectangle or arrow. Arrows attach to the shapes near their ends. Off by default. |
| **Make figure** | Groups the selected shapes into a figure you can embed in a note. |
| **Ungroup** | Dissolves a figure, or lifts shapes out of it. |
| **Rearrange** | Lays out the selection (or the whole canvas) **vertically** or **horizontally**. Undo from the "Rearranged" message. |

## Figures

A figure is a named part of a canvas, like "Request path" or "Data model".

1. Select some shapes and click **Make figure**.
2. Double-click the figure's title bar to rename it.
3. Drag the figure's handle into a note to embed it, or add a **Figure** block in the note.

The embedded figure updates when you change the drawing (a few seconds after the canvas saves).

On a published canvas, readers can jump between figures from the minimap on the right edge (on phones, the **Figures** button).

## Draw from text

Agents and the CLI can create a canvas from a mermaid flowchart or class diagram. Every box and arrow is a real, editable shape. See [Writing content](/agents/writing-content#canvases-mermaid-flowcharts).

<Note>The canvas follows your light or dark theme. Thumbnails and embedded figures always render on a light background.</Note>
