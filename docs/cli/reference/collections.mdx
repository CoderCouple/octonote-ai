## collection list

List your collections and how many clips each holds. Alias: <code>ls</code>.

```bash

```

| Argument or option | What it does |
| --- | --- |

## collection compose

Write a note from a collection's clips with AI, every sentence cited to its clip (prints the draft; --save keeps it)

```bash
octonote collection compose <collection> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;collection&gt;</code> | collection id (clc_…) (required) |
| <code>-m, --mode &lt;mode&gt;</code> | summary \| report \| comparison \| study_notes \| outline \| faq \| article \| brief \| flashcards \| custom (default: summary) |
| <code>-i, --instructions &lt;text&gt;</code> | what to focus on (required for --mode custom) |
| <code>-t, --title &lt;title&gt;</code> | the note's title (default: chosen by the AI) |
| <code>--save</code> | save the draft as a note and print its link |
| <code>-n, --notebook &lt;notebook&gt;</code> | with --save: put the note in this notebook (id or exact name) |

## clip add

```bash
octonote clip add <collection> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;collection&gt;</code> | collection id (clc_…) (required) |
| <code>-t, --text &lt;text&gt;</code> | the clip's text, inline |
| <code>-f, --file &lt;path&gt;</code> | read it from a file ("-" for stdin) |
| <code>--stdin</code> | read it from stdin |
| <code>--source-url &lt;url&gt;</code> | where it came from |
| <code>--source-title &lt;title&gt;</code> | the page or chat it came from |
| <code>--app &lt;app&gt;</code> | which app: chatgpt \| claude \| gemini \| octonote \| web \| other |
