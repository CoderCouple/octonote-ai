## deck create

Create a presentation from slide markdown (--- between slides, ??? before a slide's notes), or empty

```bash
octonote deck create [title] [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;title&gt;</code> | title (default: Untitled presentation) |
| <code>-f, --file &lt;path&gt;</code> | slide markdown file ("-" for stdin) |
| <code>--stdin</code> | read slide markdown from stdin |
| <code>-n, --notebook &lt;notebook&gt;</code> | put it in a notebook (id or exact name) |
| <code>--publish</code> | publish it to the web and print the public URL |

## deck from

Make a presentation from a note, project or notebook (the original stays as it is)

```bash
octonote deck from <source> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;source&gt;</code> | note (pag_…), project (prj_…) or notebook (ntb_…) id or URL (required) |
| <code>--split &lt;at&gt;</code> | a new slide at each heading (H1/H2) or each divider (---) (default: heading) |
| <code>--keep-text</code> | keep paragraphs on the slides (default: they go to the presenter notes) |
| <code>--group-blocks</code> | keep a section's blocks on one slide (default: each block gets its own) |
| <code>--ai</code> | let AI design it: short points, the presenter notes, the blocks kept (uses the AI allowance; takes about half a minute) |
| <code>-t, --title &lt;title&gt;</code> | title (default: the source's) |
| <code>-n, --notebook &lt;notebook&gt;</code> | put it in a notebook (default: the source's) |
| <code>--publish</code> | publish it to the web and print the public URL |

## deck show

Print a presentation as an outline: each slide's layout, title, blocks and notes. Alias: <code>read</code>.

```bash
octonote deck show <deck>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;deck&gt;</code> | presentation id (dck_…) or URL (required) |

## deck pull

Save a presentation as JSON (&#123; version: 1, slides &#125;) to edit and push back

```bash
octonote deck pull <deck> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;deck&gt;</code> | presentation id (dck_…) or URL (required) |
| <code>-o, --out &lt;path&gt;</code> | file to write (default: &lt;id&gt;.json) |

## deck push

Replace a presentation with JSON from `deck pull` (checked before it's saved)

```bash
octonote deck push <file> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;file&gt;</code> | presentation JSON ("-" for stdin) (required) |
| <code>--id &lt;deck&gt;</code> | presentation to update (required) |
