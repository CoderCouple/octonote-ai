## login

Sign in through the browser (or --paste a token from Settings → CLI &amp; agents)

```bash
octonote login [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>--paste</code> | read a token from stdin instead of opening the browser |

## logout

Sign out here and revoke this computer's token

```bash
octonote logout
```

## whoami

Who you're signed in as, and which workspace commands use

```bash
octonote whoami
```

## account rename

Change your display name (shown in the app and as the author of pages you publish)

```bash
octonote account rename <name>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;name&gt;</code> | new display name, 1–80 characters (required) |

## workspace list

Workspaces you belong to

```bash
octonote workspace list
```

## workspace use

Use this workspace from now on (id or exact name)

```bash
octonote workspace use <workspace>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;workspace&gt;</code> | workspace id or name (required) |

## token list

List your tokens

```bash
octonote token list
```

## token revoke

Revoke a token

```bash
octonote token revoke <id>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | token id (tok_…) (required) |
