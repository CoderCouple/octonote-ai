## publish

Publish to the web; prints the public URL

```bash
octonote publish <id>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | any Octonote id (required) |

## unpublish

Stop publishing to the web

```bash
octonote unpublish <id>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | any Octonote id (required) |

## share

Share with a person by email, or set who can open the link

```bash
octonote share <id> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | any Octonote id (required) |
| <code>-e, --email &lt;email&gt;</code> | invite this person (they get an email; non-users join on sign-up) |
| <code>-r, --role &lt;role&gt;</code> | viewer \| editor (default: viewer) |
| <code>--link &lt;access&gt;</code> | anyone with the link: off \| view \| edit |
