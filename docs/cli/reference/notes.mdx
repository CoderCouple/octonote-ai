## note create

Create a note, optionally filled from markdown

```bash
octonote note create [title] [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;title&gt;</code> | title (defaults to the file's front matter / first heading) (optional) |
| <code>-f, --file &lt;path&gt;</code> | markdown file ("-" for stdin) |
| <code>--stdin</code> | read markdown from stdin |
| <code>-n, --notebook &lt;notebook&gt;</code> | put it in a notebook (id or exact name) |
| <code>--publish</code> | publish it to the web and print the public URL |

## note show

Print a note as markdown. Alias: <code>read</code>.

```bash
octonote note show <note>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;note&gt;</code> | note id (pag_…) or URL (required) |

## note pull

Save a note to a markdown file (with front matter, so `note push` knows which note it is)

```bash
octonote note pull <note> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;note&gt;</code> | note id (pag_…) or URL (required) |
| <code>-o, --out &lt;path&gt;</code> | file to write (default: &lt;id&gt;.md) |

## note push

Replace a note's content with a markdown file (uses the file's front matter id, or --id)

```bash
octonote note push <file> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;file&gt;</code> | markdown file ("-" for stdin) (required) |
| <code>--id &lt;note&gt;</code> | note to update (overrides the front matter) |

## note append

Add markdown to the end of a note

```bash
octonote note append <note> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;note&gt;</code> | note id (pag_…) or URL (required) |
| <code>-f, --file &lt;path&gt;</code> | markdown file ("-" for stdin) |
| <code>--stdin</code> | read markdown from stdin |
| <code>-t, --text &lt;markdown&gt;</code> | markdown given inline |

## note rename

Rename a note

```bash
octonote note rename <note> <title>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;note&gt;</code> | note id (pag_…) (required) |
| <code>&lt;title&gt;</code> | new title (required) |
