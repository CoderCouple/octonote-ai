## setup

Teach an agent to use Octonote: writes a section into CLAUDE.md (claude), AGENTS.md (codex) or GEMINI.md (gemini)

```bash
octonote setup <agent> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;agent&gt;</code> | claude \| codex \| gemini (required) |
| <code>--dir &lt;path&gt;</code> | project folder (default: .) |
| <code>--global</code> | for every project: ~/.claude/CLAUDE.md, ~/.codex/AGENTS.md or ~/.gemini/GEMINI.md |
| <code>--skill</code> | claude only: also install the Octonote skill (.claude/skills/octonote) |
