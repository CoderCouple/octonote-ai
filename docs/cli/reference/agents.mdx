## setup

Teach an agent to use Octonote: writes a section into CLAUDE.md (claude) or AGENTS.md (codex)

```bash
octonote setup <agent> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;agent&gt;</code> | claude \| codex (required) |
| <code>--dir &lt;path&gt;</code> | project folder (default: .) |
| <code>--global</code> | for every project: ~/.claude/CLAUDE.md or ~/.codex/AGENTS.md |
| <code>--skill</code> | claude only: also install the Octonote skill (.claude/skills/octonote) |
