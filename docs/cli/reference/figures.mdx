## figure list

List figures, in the workspace or on one canvas. Alias: <code>ls</code>.

```bash
octonote figure list [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>-c, --canvas &lt;canvas&gt;</code> | only this canvas's figures (cnv_…) |

## figure show

A figure's details and link

```bash
octonote figure show <figure>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;figure&gt;</code> | figure id (fig_…) (required) |

## figure download

Save a figure as a PNG

```bash
octonote figure download <figure> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;figure&gt;</code> | figure id (fig_…) (required) |
| <code>-o, --out &lt;path&gt;</code> | file to write (default: &lt;id&gt;.png) |
