## canvas create

Create a canvas — drawn from a mermaid flowchart, from tldraw JSON, or empty

```bash
octonote canvas create [title] [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;title&gt;</code> | title (default: Untitled canvas) |
| <code>-m, --from-mermaid &lt;path&gt;</code> | mermaid flowchart file ("-" for stdin) to draw as real shapes |
| <code>-f, --file &lt;path&gt;</code> | tldraw snapshot JSON (from `canvas pull`) |
| <code>-n, --notebook &lt;notebook&gt;</code> | put it in a notebook (id or exact name) |
| <code>--publish</code> | publish it to the web and print the public URL |

## canvas redraw

Replace a canvas with a drawing of a mermaid flowchart

```bash
octonote canvas redraw <canvas> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;canvas&gt;</code> | canvas id (cnv_…) or URL (required) |
| <code>-m, --from-mermaid &lt;path&gt;</code> | mermaid flowchart file ("-" for stdin) (required) |

## canvas pull

Save a canvas as tldraw JSON

```bash
octonote canvas pull <canvas> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;canvas&gt;</code> | canvas id (cnv_…) or URL (required) |
| <code>-o, --out &lt;path&gt;</code> | file to write (default: &lt;id&gt;.json) |

## canvas push

Replace a canvas with tldraw JSON (from `canvas pull`)

```bash
octonote canvas push <file> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;file&gt;</code> | tldraw snapshot JSON ("-" for stdin) (required) |
| <code>--id &lt;canvas&gt;</code> | canvas to update (required) |
