## project create

Create a project; fill its note from markdown and draw its canvas from mermaid in one go

```bash
octonote project create <name> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;name&gt;</code> | project name (required) |
| <code>-d, --description &lt;text&gt;</code> | one-line description |
| <code>--note &lt;path&gt;</code> | markdown file for the project's note ("-" for stdin) |
| <code>--canvas-mermaid &lt;path&gt;</code> | mermaid flowchart file to draw on the project's canvas |
| <code>--view &lt;view&gt;</code> | what readers see first: notes \| canvas \| split (default: split) |
| <code>-n, --notebook &lt;notebook&gt;</code> | put it in a notebook (id or exact name) |
| <code>--publish</code> | publish it to the web and print the public URL |

## project show

Show a project and the ids of its note and canvas

```bash
octonote project show <project>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;project&gt;</code> | project id (prj_…) or URL (required) |
