Add `--help` to any command in your terminal for the same details.

## Global options

These work with every command.

| Option | What it does |
| --- | --- |
| <code>--json</code> | JSON output (default when piped) |
| <code>--pretty</code> | human output (default in a terminal) |
| <code>-q, --quiet</code> | no progress messages |
| <code>-w, --workspace &lt;id&gt;</code> | workspace to use (default: yours) |
| <code>--api-url &lt;url&gt;</code> | Octonote API (default: OCTONOTE_API_URL or the hosted API) |
| <code>--web-url &lt;url&gt;</code> | Octonote web app (default: OCTONOTE_WEB_URL or https://octonote.ai) |
