## generate

Write a whole note with AI from a request (text, diagrams and interactive blocks); saves it as a note

```bash
octonote generate <request…> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;request&gt;</code> | what the note should be, e.g. "explain backpropagation with a quiz" (required) |
| <code>-t, --title &lt;title&gt;</code> | the note's title (default: its first heading) |
| <code>-n, --notebook &lt;notebook&gt;</code> | put it in a notebook (id or exact name) |
| <code>-o, --out &lt;path&gt;</code> | write the markdown to a file instead of making a note |

## studio create

Make a Studio item from one source (it's made in the background; --wait waits for it)

```bash
octonote studio create [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>-k, --kind &lt;kind&gt;</code> | mindmap \| flashcards \| quiz \| mcq \| matching \| infographic \| text (required) |
| <code>--text &lt;text&gt;</code> | the source text, inline |
| <code>-f, --file &lt;path&gt;</code> | source text from a file ("-" for stdin) |
| <code>--stdin</code> | source text from stdin |
| <code>--url &lt;url&gt;</code> | a web page |
| <code>--from &lt;id&gt;</code> | a note, canvas or project (pag_… / cnv_… / prj_…) |
| <code>--pdf &lt;path&gt;</code> | a PDF, up to 7 MB |
| <code>-t, --title &lt;title&gt;</code> | its title (default: chosen by the AI) |
| <code>--wait</code> | wait until it's made, then print it |
