## list

List notes, canvases, projects and notebooks (newest first). Alias: <code>ls</code>.

```bash
octonote list [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>-k, --kind &lt;kind&gt;</code> | only this kind: note \| canvas \| project \| notebook |
| <code>-n, --notebook &lt;notebook&gt;</code> | only what's inside this notebook (id or exact name) |

## search

Find notes, canvases, projects and notebooks by title

```bash
octonote search <query…>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;query&gt;</code> | words to look for in titles (required) |

## open

Print the app link for an item (and open it when run in a terminal)

```bash
octonote open <id>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | any Octonote id or URL (required) |

## move

Move a note, canvas or project into a notebook (or out with --out)

```bash
octonote move <id> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | note, canvas or project id (required) |
| <code>-n, --notebook &lt;notebook&gt;</code> | target notebook (id or exact name) |
| <code>--out</code> | take it out of its notebook |

## delete

Delete a note, canvas, project or notebook (a notebook's contents move to the top level). Alias: <code>rm</code>.

```bash
octonote delete <id> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | any Octonote id (required) |
| <code>-y, --yes</code> | required: confirms the delete (agents: only when the user asked) |
