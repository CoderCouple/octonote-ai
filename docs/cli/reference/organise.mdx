## list

List notes, canvases, projects, notebooks and presentations (newest first). Alias: <code>ls</code>.

```bash
octonote list [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>-k, --kind &lt;kind&gt;</code> | only this kind: note \| canvas \| project \| notebook \| presentation |
| <code>-n, --notebook &lt;notebook&gt;</code> | only what's inside this notebook (id or exact name) |

## search

Find notes, canvases, projects, notebooks and presentations by title

```bash
octonote search <query…>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;query&gt;</code> | words to look for in titles (required) |

## open

Print the app link for an item (and open it when run in a terminal)

```bash
octonote open <id>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | any Octonote id or URL (required) |

## move

Move a note, canvas, project or presentation into a notebook (or out with --out)

```bash
octonote move <id> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | note, canvas or project id (required) |
| <code>-n, --notebook &lt;notebook&gt;</code> | target notebook (id or exact name) |
| <code>--out</code> | take it out of its notebook |

## rename

Rename a note, canvas, project, notebook or presentation

```bash
octonote rename <id> <name>
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | any Octonote id (required) |
| <code>&lt;name&gt;</code> | new name (required) |

## delete

Delete a note, canvas, project, notebook or presentation (a notebook's contents move to the top level). Alias: <code>rm</code>.

```bash
octonote delete <id> [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>&lt;id&gt;</code> | any Octonote id (required) |
| <code>-y, --yes</code> | required: confirms the delete (agents: only when the user asked) |

## recent

What you edited lately, most recent first

```bash
octonote recent
```

## activity

The workspace's change history, newest first (or one item's)

```bash
octonote activity [options]
```

| Argument or option | What it does |
| --- | --- |
| <code>-i, --item &lt;id&gt;</code> | only changes to this item |
| <code>-l, --limit &lt;n&gt;</code> | how many, up to 200 (default: 50) |
