# Layout corpus

Diagram-as-code examples used to reverse-engineer Eraser's layout and styling.
Each `NN-name.eraser` file is plain Eraser syntax.

For each example, paste the code into Eraser, then save next to it:

- `NN-name.json` — the JSON Eraser generated (same format as `packages/octodraw/test/fixtures/eraser-food-delivery.json`)
- `NN-name.png` — an export of the rendered diagram (optional, used for visual comparison)

The playground's compare view (`http://localhost:5180/?compare`) shows octodraw's layout next to Eraser's for every example that has a `.json`.
